Metric Guide

Total tokens
Overall context handled by Codex. Spikes often mean complex work or long loops.
Cache ratio
Cached input divided by input. Higher usually means more context reuse.
Output/input
Generated output compared with context read. High means generation-heavy; low means context-heavy.
Memory candidates
Repeated high-token work that may deserve a memory note, project guide, or skill.
